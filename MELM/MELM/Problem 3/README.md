### Problem 3: Two-Dimensional Steady Convection–Diffusion Problem (Discontinuous Boundary Conditions)

### 1. Problem Description

Consider the steady two-dimensional convection–diffusion equation

$$
a_x\frac{\partial \phi}{\partial x}
+a_y\frac{\partial \phi}{\partial y}
-k\left(
\frac{\partial^2\phi}{\partial x^2}
+\frac{\partial^2\phi}{\partial y^2}
\right)=0,
\qquad (x,y)\in\Omega,
$$

where

$$
\Omega=\left(-\frac12,\frac12\right)
\times\left(-\frac12,\frac12\right).
$$

The equation is subject to the discontinuous Dirichlet boundary conditions

$$
\phi(x,y)=
\begin{cases}
1, & y=\dfrac{1}{2}, \\[2mm]
1, & x=-\dfrac{1}{2},\quad \dfrac{1}{4}\le y\le\dfrac{1}{2}, \\[2mm]
0, & \text{otherwise on } \partial\Omega.
\end{cases}
$$

The problem parameters are:

- Convection coefficients: $$a_x=\frac{1}{\sqrt{5},}\qquad a_y=-\frac{2}{\sqrt{5}}$$
- Convection velocity magnitude: $$U=1$$
- Diffusion coefficient: $$k=0.001$$
- Domain length: $$L=1$$

The corresponding Péclet number is

$$
\mathrm{Pe}=\frac{UL}{k}=1000.
$$

### 2. Reference Solution

An exact analytical solution is not available for this problem. Therefore, the finite element method (FEM) solution is used as the reference solution for evaluating the numerical results. The FEM solution is included in `P3_PINN.csv` along with the PINN results.

### 3. Files and Results

| File | Description |
|---|---|
| `P3.py` | Python implementation of Legendre-MELM. |
| `P3_MELM.csv` | MELM numerical results generated by `P3.py` and used by `Plots.py`. |
| `P3_PINN.csv` | PINN numerical results and FEM reference solution; required to run `P3.py` and `Plots.py`. |
| `P3_bnd_com.pdf` | Boundary results comparison plot. |
| `P3_contour.pdf` | Contour plot of the solution. |
| `P3_error.pdf` | Error plot. |
| `P3_int_com.pdf` | Interior results comparison plot. |
| `P3_surface.pdf` | Surface plot of the solution. |
| `Plots.py` | Python script for generating plots using `P3_MELM.csv` and `P3_PINN.csv`. |

### 4. How to Run

Run the scripts from the directory containing the required files, in the following order:

```bash
python P3.py
python Plots.py
```

`P3.py` reads `P3_PINN.csv` and generates `P3_MELM.csv`. `Plots.py` uses both CSV files to generate the plots.
